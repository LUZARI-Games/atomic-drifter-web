GODOT ENGINE

        

          
          
          
        

        

        
Interior layout for Godot 4, separate from the Unreal export. Meters · origin = ship center on the floor · +Y up · bow = −Z · starboard = +X. Floor tiles, half walls (1 m, door gaps already cut) and sliding doors. Save it into res://data/ships/.

      

      

        
BLENDER EXPORT

        

          
        

        

          
          
        

        
1:1 in meters · origin = ship center · bow = −Y (Blender front) · screen up = +X · floor = Z 0 · Machine_* = machinery blocks (1.6 m) · Ref_SplitPlane = top of the walls (base/lid seam). Blender: File › Import › Wavefront (.obj), default axes.
